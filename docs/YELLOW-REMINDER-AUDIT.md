## 已有的有效保护

- 报告必须带当前绑定 generation 与递增 sequence；过期绑定和旧报告不能覆盖当前状态。
- 解析问题必须匹配待答问题 ID。新用户消息、工具完成和任务结束都不会自动清除问题；问题未解析时，路线图更新被阻止。
- 黄灯代表待处理的决策，红灯代表所需信息；信息仍在原 Codex、系统窗口或终端输入，Pet 不收集密码。
- 当前桥接不强制暂停或恢复全部 Agent，也不自动检测系统密码窗口；额度是带时间的对话缓存，独立 CLI 实时探针尚未接为自动数据源。

这些保护校验的是状态与报告顺序，不能独立证明用户已经回答，也不能证明所有子 Agent 已停止。主 Agent 仍需核对实际情况。
